5.5 Daily Standup Memory Through Your Harness

A standup memory chain turns daily progress into searchable project history. In normal use, ask your MCP-connected coding agent to write the memory for you instead of running CLI commands by hand.

Save today's update

Use MentisDB to save today's standup update.

Chain: team-standup
Thought type: TaskComplete
Agent id: my-name-or-agent-name
Content: Finished invoice export retry handling; blocked on staging credentials.
Tags: standup, backend, blocked
Concepts: billing, invoices, staging-credentials

Before appending, search the chain for related invoice-export blockers so this does not duplicate an existing memory.

Search yesterday's blockers

Search MentisDB in the team-standup chain for yesterday's blockers about staging credentials and invoice export. Summarize the top hits, including thought type, agent id, and whether each blocker is still unresolved.

What the agent should do

  • Call mentisdb_ranked_search before appending.
  • Append a typed TaskComplete, Finding, Constraint, or Question only if the update is durable.
  • Use tags for workflow labels like standup or blocked.
  • Use concepts for reusable topics like invoice-export or staging-credentials.
Operator rule: if the agent cannot show the MCP search and append calls it made, treat the standup as not saved.
