5.5 CLI: Daily Standup Memory

A standup memory chain turns daily progress into searchable project history. Save decisions, blockers, and next steps as structured thoughts rather than chat notes.

mentisdb append \
  --chain team-standup \
  --agent-id alice \
  --type TaskComplete \
  --tags standup,backend \
  --concepts billing,invoices \
  "Finished invoice export retry handling; blocked on staging credentials."

Search yesterday's blockers

mentisdb search \
  --chain team-standup \
  --text "staging credentials blocker" \
  --limit 5

Even if your exact CLI flags differ by release, keep the structure: chain, agent, type, tags, concepts, content.
